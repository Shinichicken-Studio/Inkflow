# 溢彩畫 · Inkflow

仿《鳴潮：溢彩畫》的染色擴張益智遊戲。從畫布中央的起點出發，每一步選擇一種新顏色，
讓主區塊連鎖吞併相鄰的同色格子，在步數上限內把整個畫布染成目標顏色。

## 遊玩方式

直接用瀏覽器開啟 `index.html` 即可（無需伺服器、無外部資源）。

- **點右側色盤**（或按 `1`–`5`）選擇新顏色，染色會以波紋從中心向外擴散並繞過障礙物
- 與主區塊當前顏色相同的按鈕會鎖定為「目前」不可點擊
- **提示**（`H`）：內建最佳解求解器，閃爍建議的下一手；若剩餘步數已不可能通關會直接告訴你
- **重試**（`R`）重玩本關、**新關卡**（`N`）隨機產生下一關
- 難度：簡單 8×8／普通 10×10／困難 12×12（5 色）
- 帶 ✕ 的黑色格子是障礙物：不可染色、不可穿透

每一關都由產生器隨機生成，並經 BFS 求解器驗證**保證可解**；步數上限即最佳解步數（par），
所以每一關都是「剛好能過」的緊湊謎題。

## 規則細節

1. 選新顏色 → 與起點相連的同色主區塊全部變色
2. 變色後若邊緣接觸到原本就是新顏色的格子，會被連鎖吞併進主區塊
3. 每選一次顏色扣 1 步（即使沒吞併到任何格子）
4. 所有非障礙格 = 目標顏色 → 勝利；步數用盡未達成 → 失敗（勝利判定優先）

## 專案結構

| 檔案 | 說明 |
|---|---|
| `game.js` | 核心邏輯（UMD）：泛洪染色、吞併、勝負判定、區域圖 BFS 最佳解求解器、關卡產生器 |
| `index.html` | 遊戲介面：波紋動畫（依 BFS 距離延遲，繞過障礙物）、中心準心、結算特效、音效 |
| `test.js` | 自動化測試 |

## 測試

```
node test.js                 # 49 項核心邏輯測試（泛洪、吞併、勝負、求解器、產生器可解性）
```

UI 整合測試（headless 瀏覽器自動打完整關）：開啟 `index.html#autotest`，
結果寫入 `document.title`（`TEST:PASS` / `TEST:FAIL`）與隱藏的 `#testlog` 元素。

其他除錯掛鉤：`#easy` / `#normal` / `#hard` 指定初始難度，
`#winshot` / `#loseshot` / `#waveshot` 供截圖驗證視覺效果，
`window.__inkflow` 可在 console 直接操作遊戲狀態。
